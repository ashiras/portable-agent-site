Definition of Work

「仕事」は単なるプロンプトではない。

LLMに長大な指示を押し付けると、Softmax Crowding で重要な制約が押し潰され、Semantic Drift で迷走します。
Portable Agent では、実行状態そのものを外部ハーネスで保持します。

Harness State Formula
Work = Goal + Plan + Trajectory + Checkpoint + Control State + Artifact + Guard

この7つの状態すべてを外部ハーネスが握っているからこそ、LLMを自由に着脱できる。

Deterministic Guard

無限ループを許さない、2種類の終了条件

Exit = Success Exit ∨ Safety Exit
✓

Success Exit（成功終了）

物理的な外部検証（Guard）の完全パス

  • ● Compile が正常に通る
  • ● Unit Test が全件パスする
  • ● Linter の警告・エラーがゼロ
  • ● 指定された成果物（Artifact）が物理的に存在する
Checkpoint Commit 実行 → Human Review
⚡

Safety Exit（安全遮断）

Progress Circuit Breaker による強制停止

  • ● 最大試行回数（max_retry）に到達
  • ● 同じエラーの連続反復（2回連続 no-progress）
  • ● 許可されていない対象外ファイルの無断変更
  • ● Context / Token / 実行時間の上限到達
強制 Cut & Return → Checkpoint Failed
