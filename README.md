# portable-agent-site
Official product site for Portable Agent — Portability-first External Harness Runtime by Ashiras, Inc.


* **Gateway（Expand）**
可能性を広げる。通常の対話から複数モデル検討へ移し、コンテキストを整えて渡す。まだ Goal は未確定でよい。

* **v1 Orchestration-first（Converge）**
Shared Blackboard で論点を並べ、反論し、比較する。人間が決断できる状態、つまり Goal を作るのが仕事。オーケストレーションはここが本領。発散したまま実行に入らない。

* **v2 Portability-first（Constrain）**
決まった Goal だけを運ぶ。Guard と Checkpoint で直線実行。論点の追加はしない。モデルは差し替え可能。仕事の単位は外に残る。

多くの製品は「全部エージェント」で一段に潰す。ここは 探索・合意・実行を別製品にしたのが強い。v2 をコアに置き、前段を Gateway と v1 に分けているのも合理的で、実行系に発散を持ち込まない。

「まとまっている」ように見える理由は、技術スタックの完成度より、この Expand → Converge → Constrain の境界がビジネス単位になっている点だと思います。
